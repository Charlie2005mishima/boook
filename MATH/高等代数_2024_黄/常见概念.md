
- **正交矩阵**  
	- **定义**：实数方阵 $Q$ 满足 $Q^T Q = Q Q^T = I$（即 $Q^{-1} = Q^T$）。  
	- **核心性质**：列（行）向量组为标准正交基；保内积（$\|Qx\| = \|x\|$）和欧氏距离；行列式 $\det(Q) = \pm 1$。几何上对应旋转或反射。

- **正定矩阵**  
	- **定义**：对称实矩阵 $A$ 满足对任意非零向量 $x$，有 $x^T A x > 0$。  
	- **判定**：所有特征值 $> 0$；所有顺序主子式 $> 0$；存在可逆矩阵 $P$ 使得 $A = P^T P$。若 $\ge 0$ 则为**半正定**。

- **奇异矩阵 vs. 奇异值**  
	- **奇异矩阵**：指行列式为 0 的方阵（不可逆），其零空间存在非零向量。  
	- **奇异值**：指任意矩阵 $A$（不一定是方阵）在 SVD 分解中的对角元素 $\sigma_i$，它来源于 $A^T A$ 或 $AA^T$ 的特征值开方。**注意**：两者中文相同但概念迥异，前者是矩阵属性，后者是分解产生的标量。


- **特征分解**  
	- **适用**：仅限**可对角化方阵**（尤其是实对称矩阵）。  
	- **形式**：$A = V \Lambda V^{-1}$。若 $A$ 为实对称矩阵，则 $A = Q \Lambda Q^T$，其中 $Q$ 是正交矩阵，$\Lambda$ 是对角矩阵。  
	- **目的**：将矩阵作用看作在特征向量方向上按特征值缩放。

- **正交分解**  
	- 在线性代数中通常指两种情形：
	- **QR 分解**：任意实矩阵 $A_{m\times n}$ 分解为 $A = QR$，其中 $Q$ 是列正交矩阵，$R$ 是上三角矩阵（用于最小二乘和 Gram-Schmidt 过程）。
	- **正交对角化**：即上述对称矩阵的特殊特征分解（$A = Q \Lambda Q^T$）。

- **奇异值分解**
	- **通用性最强**：适用于任意矩阵 $A \in \mathbb{R}^{m \times n}$。  
	- **形式**：$A = U \Sigma V^T$。  
	- $U_{m \times m}$、$V_{n \times n}$ 为正交矩阵（左/右奇异向量）；  
	- $\Sigma_{m \times n}$ 为对角矩阵，对角元素 $\sigma_1 \ge \sigma_2 \ge ... \ge 0$（奇异值）。  
	- **意义**：将任意线性变换分解为“旋转/反射 → 缩放 → 旋转/反射”。它是特征分解的普适推广（当 $A$ 对称正定时，SVD 退化为特征分解）。


- **特征值与特征向量**  
	- **定义**：对于方阵 $A$，若存在非零向量 $v$ 和标量 $\lambda$ 使 $Av = \lambda v$，则 $\lambda$ 为特征值，$v$ 为对应特征向量。  
	- **求法**：解特征多项式 $\det(\lambda I - A) = 0$。  
	- **关联**：矩阵的迹等于特征值之和；行列式等于特征值之积。

- **Moore-Penrose 伪逆**  
	- **定义**：对于任意矩阵 $A$（含奇异/非方阵），存在唯一的伪逆 $A^+$，满足四个 Penrose 条件。  
	- **计算（基于 SVD）**：若 $A = U \Sigma V^T$，则 $A^+ = V \Sigma^+ U^T$，其中 $\Sigma^+$ 是将 $\Sigma$ 中非零奇异值取倒数后转置得到的矩阵。  
	- **应用**：求解最小二乘问题的最小范数解 $x = A^+ b$（当 $A$ 列满秩时，退化为 $(A^T A)^{-1}A^T$）。


- **迹运算 (Trace)**  
	- **定义**：方阵主对角线元素之和，$\text{tr}(A) = \sum_i A_{ii}$。  
	- **核心性质**：  
	- 循环不变性：$\text{tr}(ABC) = \text{tr}(BCA) = \text{tr}(CAB)$（乘积分步可交换循环顺序）。  
	- 与特征值关系：$\text{tr}(A) = \sum \lambda_i$。  
	- 与内积关系：Frobenius 范数的平方 $\|A\|_F^2 = \text{tr}(A^T A)$。

- **矩阵/向量微积分 (Matrix Calculus)**  
	- 主要涉及**标量函数对向量/矩阵的求导**（分母布局与分子布局注意转置差异）。核心高频公式（采用**分母布局**，即结果为列向量或矩阵）：
  
  - **向量对向量**（雅可比矩阵）。
  - **标量对向量**：
    - $\frac{\partial (a^T x)}{\partial x} = a$
    - $\frac{\partial (x^T A x)}{\partial x} = (A + A^T)x$（若 $A$ 对称，则为 $2Ax$）
  - **标量对矩阵**：
    - $\frac{\partial \text{tr}(AB)}{\partial A} = B^T$
    - $\frac{\partial \text{tr}(A^T B)}{\partial A} = B$
    - $\frac{\partial \text{tr}(X^T A X)}{\partial X} = (A + A^T)X$
  - **重要应用**：线性回归最小二乘的解析解推导，正是利用 $\nabla_x \|Ax - b\|_2^2 = 2A^T(Ax - b)$ 并令其为零得到正规方程 $A^T A x = A^T b$。

- 核空间（零空间，Null Space / Kernel）
	- **定义**：对于矩阵 $A \in \mathbb{R}^{m \times n}$，其核空间定义为所有被 $A$ 映射到零向量的向量集合：$\text{Ker}(A) = \{ x \in \mathbb{R}^n \mid Ax = 0 \}$它是 $\mathbb{R}^n$ 的一个子空间。
