具有两个自变量的二阶偏微分方程是最基本的一类二阶方程。

## §1 拟线性二阶方程的特征

关于二元函数 $u(x,y)$ 的一般拟线性二阶方程具有形式 $a u_{xx} + 2b u_{xy} + c u_{yy} = d$ (1.1)
其中 $a,b,c,d$ 是依赖于变量 $x,y,u,u_x,u_y$ 的已知函数。

**※【定义3.1】** Cauchy 问题
Cauchy 问题是指求方程 (1.1) 的解 $u$，使得在 $(x,y)$ 平面内的曲线 $l$ 上 $u,u_x,u_y$ 取给定的（相容的）值。

对具有参数表示 $x = f(s), \quad y = g(s)$ (1.2) 的曲线 $l$，
在 $l$ 上给定 Cauchy 数据 $u = h(s), \quad u_x = \varphi(s), \quad u_y = \psi(s)$ (1.3) 
其中 $h(s),\varphi(s),\psi(s)$ 适当光滑。

沿着曲线 $l$，任意函数 $v(x,y)$ 及其一阶偏导数满足相容性条件 $\frac{dv}{ds} = v_x f'(s) + v_y g'(s)$ (1.4)
特别地，对 Cauchy 问题的解 $u$，其 Cauchy 数据满足 $h'(s) = \varphi(s) f'(s) + \psi(s) g'(s)$ (1.5)
(1.5) 称为 Cauchy 问题的相容性条件。由 (1.5) 可知，$h(s),\varphi(s),\psi(s)$ 中只有两个独立。

也可在 $l$ 上给定 $u$ 的值及其法向导数的值 $u = h(s), \quad (u_x,u_y)\cdot\left(\frac{-g'}{\sqrt{f'^2+g'^2}}, \frac{f'}{\sqrt{f'^2+g'^2}}\right) = i(s)$ (1.6)

**※【注记3.1】** 
$l$ 上的任意函数的高阶偏导数也满足相容性条件。例如
$\frac{du_x}{ds} = u_{xx} f'(s) + u_{xy} g'(s), \quad \frac{du_y}{ds} = u_{yx} f'(s) + u_{yy} g'(s)$ (1.7)
类似关系对 $u_{xx},u_{xy},u_{yy},\cdots$ 关于 $s$ 的全导数也成立。

假设 $u$ 是 Cauchy 问题 (1.1) 和 (1.3) 的解，则沿曲线 $l$ 成立关于 $u_{xx},u_{xy},u_{yy}$ 的三个线性方程
$\begin{cases} a u_{xx} + 2b u_{xy} + c u_{yy} = d, \\ f' u_{xx} + g' u_{xy} = \varphi', \\ f' u_{xy} + g' u_{yy} = \psi', \end{cases}$ (1.8)
其中系数是 $s$ 的已知函数。能唯一确定 $u_{xx},u_{xy},u_{yy}$ 的条件是
$\Delta \triangleq \begin{vmatrix} f' & g' & 0 \\ 0 & f' & g' \\ a & 2b & c \end{vmatrix} \neq 0$ (1.9)
若沿初始曲线 $l$ 有 $\Delta = 0$ (1.10) 则称 $l$ 是关于偏微分方程及相应数据的特征；
若 (1.9) 成立，则称 $l$ 是非特征。
沿非特征曲线，Cauchy 数据可唯一确定二阶偏导数在 $l$ 上的值，并可依次解出高阶导数。

当初始曲线 $l$ 是特征时，方程 (1.8) 一般无解，即在特征曲线上给出 Cauchy 数据的 Cauchy 问题一般无解。

特征曲线条件 (1.10) 可改写为 $a (dy)^2 - 2b dxdy + c (dx)^2 = 0$ (1.13)
求解 $\frac{dy}{dx}$ 得 $\frac{dy}{dx} = \frac{b \pm \sqrt{b^2 - ac}}{a}$ (1.14)
当特征曲线由 $\chi(x,y) =$ 常数 隐式给出时，沿 $l$ 有 $\chi_x dx + \chi_y dy = 0$ (1.15)
从而 (1.13) 变为 $a \chi_x^2 + 2b \chi_x \chi_y + c \chi_y^2 = 0$ (1.16)
特别地，当 $a,b,c$ 是 $x,y$ 的已知函数，或 (1.1) 是线性时，(1.14) 是常微分方程。

**※【定义3.2】** 方程类型
当 $ac - b^2 > 0$ 时，称方程 (1.1) 为椭圆型的；
当 $ac - b^2 < 0$ 时，称为双曲型的；
当 $ac - b^2 = 0$ 时，称为抛物型的。

**※【注记3.2】** 
双曲型方程有两族不同的特征线；
抛物型方程有一族特征线；
椭圆型方程没有特征线。

**※【注记3.3】** 
在非线性情形，方程的类型不是仅由方程确定的，还与具体的解有关。
即使线性方程，在不同区域也可以是不同类型的，甚至是混合型的。

## §2 奇性的传播

特征线与解的某种类型的奇性的传播有密切关系。

解的奇性指解的间断性或不连续性。

定义方程 (1.1) 的不一定属于 $C^2$ 类的广义解的一种自然方法是考虑其二阶导数沿曲线 $l$ 有跳跃间断（第一类间断）的 $C^1$ 解，这种奇性称为弱间断。

假设区域 $\Omega$ 被曲线 $l$ 分成 $\Omega_+$ 和 $\Omega_-$，存在解 $u^+$ 和 $u^-$ 分别在 $\overline{\Omega}_+$ 和 $\overline{\Omega}_-$ 上属于 $C^2$。
定义 $u = \begin{cases} u^+, & \text{在 } \Omega_+ \text{ 上}, \\ u^-, & \text{在 } \Omega_- \text{ 上}. \end{cases}$ (2.1)
拼凑出的 $u$ 通常不能看作广义解，除非在 $l$ 上满足某种跳跃性条件。

最简单情形是要求 $u \in C^1$，即 $u^+$ 和 $u^-$ 及其一阶偏导数在 $l$ 上相等。
若二阶偏导数也相等，则 $u$ 是 $C^2$ 严格解。
感兴趣的是二阶偏导数在 $l$ 上不相等的情形。只有 $l$ 为特征曲线时，二阶偏导数才可能在 $l$ 上出现间断。

讨论具光滑系数 $a,b,c,d,e,f,h$ 的二阶线性方程
$\mathcal{L}u \triangleq a(x,y)u_{xx} + 2b(x,y)u_{xy} + c(x,y)u_{yy} + 2d(x,y)u_x + 2e(x,y)u_y + f(x,y)u + h(x,y) = 0$ (2.2)
假设 $\Omega$ 是开集，$l$ 是 $\Omega$ 中的曲线，$\Omega\backslash l$ 由两个不相交开集 $\Omega_+$ 和 $\Omega_-$ 组成。设 $l$ 由 $x = \varphi(y)$ 给出，$\varphi$ 适当光滑。

**※【定义3.3】** 有跳跃的不连续性
称定义在 $\Omega$ 内的函数 $u$ 沿曲线 $l$ 有跳跃的不连续性，如果在 $\Omega_\pm$ 内 $u = u^\pm$，其中 $u^\pm$ 在 $\Omega_\pm \cup l$ 上连续但在 $l$ 上 $u^+ \neq u^-$。

用 $[u] = u^+(\varphi(y),y) - u^-(\varphi(y),y)$ (2.3) 表示 $u$ 在 $l$ 上的点 $(\varphi(y),y)$ 处的跳跃量。
沿 $l$ 有 $\frac{d[u]}{dy} = [u_x]\varphi' + [u_y]$ (2.4)
当 $u$ 沿 $l$ 连续时 $[u]=0$，两端关于 $y$ 求导得 $[u_x]\varphi' + [u_y] = 0$ (2.5)

假设 $u^\pm \in C^3$ 且分别在 $\Omega_\pm \cup l$ 上满足 (2.2)，但 $u$ 在 $\Omega$ 内属于 $C^1$。
则 $[u] = [u_x] = [u_y] = 0$ (2.6)
将 $u^\pm$ 满足的方程相减得 $a[u_{xx}] + 2b[u_{xy}] + c[u_{yy}] = 0$ (2.7)
对 $[u_x]=0$ 和 $[u_y]=0$ 关于 $y$ 求导得
$[u_{xx}]\varphi' + [u_{xy}] = 0, \quad [u_{xy}]\varphi' + [u_{yy}] = 0$ (2.8)
(2.8) 表明二阶偏导数的跳跃量不独立。
令 $[u_{xx}] = \delta$，则 $[u_{xx}] = \delta, \quad [u_{xy}] = -\varphi'\delta, \quad [u_{yy}] = \varphi'^2\delta$ (2.9)
由 (2.7) 推出 $a - 2b\varphi' + c\varphi'^2 = 0$ (2.10)
假设 $\delta \neq 0$，则 (2.10) 表明 $l$ 一定是特征曲线。$\delta$ 表示二阶偏导数跳跃强度。
若 $y$ 表示时间变量，$\varphi$ 是沿 $x$ 轴运动的点的轨迹，间断点传播速度 $\frac{dx}{dy}$ 由 (2.10) 确定。

跳跃强度 $\delta$ 沿 $l$ 满足一定规律。
对 (2.9) 前两式关于 $y$ 求导得
$\begin{cases} \delta' = [u_{xxx}]\varphi' + [u_{xxy}], \\ -(\varphi'\delta)' = [u_{xxy}]\varphi' + [u_{xyy}]. \end{cases}$ (2.11)
对 $u^\pm$ 满足的方程关于 $x$ 求导，取跳跃量得
$a[u_{xxx}] + 2b[u_{xxy}] + c[u_{xyy}] + a_x[u_{xx}] + 2b_x[u_{xy}] + c_x[u_{yy}] + 2d[u_{xx}] + 2e[u_{xy}] = 0$ (2.12)
利用 (2.9)、(2.10)、(2.11) 消去三阶偏导数得
$2(b - c\varphi')\delta' + (a_x - 2b_x\varphi' + c_x\varphi'^2 + 2d - 2e\varphi' - c\varphi'')\delta = 0$ (2.13)
这是关于 $\delta$ 的一阶齐次常微分方程。若在 $l$ 上某点 $\delta=0$，则沿整个 $l$ 均有 $\delta=0$，永远不会出现跳跃。

**※【注记3.4】** 
化简 (2.12) 中三阶偏导数项的关键步骤：
$a[u_{xxx}] + 2b[u_{xxy}] + c[u_{xyy}]$
$= (2b\varphi' - c\varphi'^2)[u_{xxx}] + 2b[u_{xxy}] + c[u_{xyy}]$
$= 2b\{\varphi'[u_{xxx}] + [u_{xxy}]\} + c\{[u_{xyy}] - \varphi'^2[u_{xxx}]\}$
$= 2b\delta' + c\{-(\varphi'\delta)' - \varphi'[u_{xxy}] - \varphi'^2[u_{xxx}]\}$
$= 2b\delta' - c\varphi''\delta - c\varphi'\delta' - c\varphi'\{[u_{xxy}] + \varphi'[u_{xxx}]\}$
$= 2b\delta' - c\varphi''\delta - c\varphi'\delta' - c\varphi'\delta'$
$= 2(b - c\varphi')\delta' - c\varphi''\delta$ (2.14)
利用 (2.14) 从 (2.12) 得到 (2.13)。

## §3 二阶线性方程的标准形

关于二元函数 $u(x,y)$ 的二阶线性方程
$a u_{xx} + 2b u_{xy} + c u_{yy} + 2d u_x + 2e u_y + f u + h = 0$ (3.1)
其中 $a,b,c,d,e,f,h$ 是 $x,y$ 的实函数。

通过变换 $\xi = \varphi(x,y), \quad \eta = \psi(x,y)$ (3.2)
引入新自变量 $\xi,\eta$，可将 (3.1) 化为
$\mathcal{L}u = A(\xi,\eta)u_{\xi\xi} + 2B u_{\xi\eta} + C u_{\eta\eta} + \cdots = 0$ (3.3)
其中
$\begin{cases} A = a\varphi_x^2 + 2b\varphi_x\varphi_y + c\varphi_y^2, \\ B = a\varphi_x\psi_x + b(\varphi_x\psi_y + \varphi_y\psi_x) + c\varphi_y\psi_y, \\ C = a\psi_x^2 + 2b\psi_x\psi_y + c\psi_y^2, \end{cases}$ (3.4)

在双曲型情形，以特征线作为新坐标曲线可简化方程。
设$\xi = \varphi(x,y) =$ 常数 $\eta = \psi(x,y)=$ 常数 (3.5) 是两族特征曲线，则 $A \equiv 0, C \equiv 0$。
方程 (3.3) 除以 $2B$ 得 $u_{\xi\eta} + D u_{\xi} + E u_{\eta} + F u + H = 0$ (3.7)
称为**双曲型方程的标准形**。
再作类光变换 $\tau = \xi + \eta, \quad s = \xi - \eta$ (3.8)
可化为 $u_{\tau\tau} - u_{ss} + \overline{D} u_{\tau} + \overline{E} u_s + \overline{F} u + \overline{H} = 0$ (3.9)

在椭圆型情形 $ac - b^2 > 0$，无实特征根。
希望通过实变换将方程化为
$u_{\xi\xi} + u_{\eta\eta} + D u_{\xi} + E u_{\eta} + F u + H = 0$ (3.10)
只需选取 $\varphi,\psi$ 使 $A = C \neq 0, \quad B = 0$ (3.11)
取方程组 $\varphi_x = \frac{b\psi_x + c\psi_y}{\sqrt{ac - b^2}}, \quad \varphi_y = -\frac{a\psi_x + b\psi_y}{\sqrt{ac - b^2}}$ (3.12)
的解即可。消去 $\varphi$ 得 $\psi$ 满足 $\left(\frac{a\psi_x + b\psi_y}{\sqrt{ac - b^2}}\right)_x + \left(\frac{b\psi_x + c\psi_y}{\sqrt{ac - b^2}}\right)_y = 0$ (3.13)
称为 Beltrami 方程。(3.10) 为椭圆型标准形。

抛物型方程的标准形为 $u_{\xi} + u_{\eta\eta} + D u_{\eta} + E u + H = 0$ (3.14)

*※【例题】* 
讨论 Tricomi 方程 $u_{yy} - y u_{xx} = 0$ (3.15) 的类型。
这里 $ac - b^2 = -y$。
当 $y<0$ 时 $-y>0$，椭圆型；
当 $y>0$ 时 $-y<0$，双曲型；
$x$ 轴上抛物型。
特征方程为 $(dx)^2 - y(dy)^2 = 0$ 或 $dx \pm \sqrt{y} dy = 0 \quad (y>0)$ (3.16)
在 $y>0$ 上半平面，特征曲线为 $3x \pm 2y^{3/2} = \text{常数}$ (3.17)
通过变换 $\xi = 3x - 2y^{3/2}, \quad \eta = 3x + 2y^{3/2}$ (3.18)
可化为标准形 $u_{\xi\eta} - \frac{1}{6}\frac{u_{\xi} - u_{\eta}}{\xi - \eta} = 0$ (3.19)

## §4 一维波动方程

一维波动方程 $\mathcal{L}u \triangleq u_{tt} - c^2 u_{xx} = 0$ (4.1)
其中 $u = u(t,x)$，$c>0$。特征线为 $x \pm ct = \text{常数}$。

作类光变换 $x + ct = \xi, \quad x - ct = \eta$ (4.2)
方程化为 $u_{\xi\eta} = 0$ (4.3)
通解为 $u = F(\xi) + G(\eta)$ (4.4)
即 $u = F(x+ct) + G(x-ct)$ (4.5)
$u \in C^2$ 当且仅当 $F,G \in C^2$。

算子分解：
$\mathcal{L} = \frac{\partial^2}{\partial t^2} - c^2\frac{\partial^2}{\partial x^2} = \left(\frac{\partial}{\partial t} - c\frac{\partial}{\partial x}\right)\left(\frac{\partial}{\partial t} + c\frac{\partial}{\partial x}\right)$ (4.6)

求解 Cauchy 问题 $t = 0: \quad u = f(x), \quad u_t = g(x)$ (4.7) 其中 $f \in C^2, g \in C^1$。

由 (4.5) 得
$u(0,x) = F(x) + G(x) = f(x)$ (4.8)
$u_t(0,x) = cF'(x) - cG'(x) = g(x)$ (4.9)
对 (4.8) 求导得
$F'(x) + G'(x) = f'(x)$ (4.10)
解得
$F'(x) = \frac{c f'(x) + g(x)}{2c}, \quad G'(x) = \frac{c f'(x) - g(x)}{2c}$ (4.11)
积分得
$\begin{cases} F(x) = \frac{f(x)}{2} + \frac{1}{2c}\int_0^x g(s)ds + \mu, \\ G(x) = \frac{f(x)}{2} - \frac{1}{2c}\int_0^x g(s)ds + \nu, \end{cases}$ (4.12) $\mu+\nu=0$。

因此$u(t,x) = \frac{1}{2}[f(x+ct) + f(x-ct)] + \frac{1}{2c}\int_{x-ct}^{x+ct} g(s)ds$ (4.13)
称为 **D'Alembert 公式**。当 $f \in C^2, g \in C^1$ 时解 $u \in C^2$。

解在点 $(t,x)$ 的值由初值在区间 $[x-ct, x+ct]$ 上的值唯一确定，该区间称为点 $(t,x)$ 的**依赖区间**。

$x$ 轴上点 $(0,\xi)$ 的影响区域为楔形区域
$\vee_{(0,\xi)} = \{(t,x) \mid t>0, \xi - ct \leqslant x \leqslant \xi + ct\}$ (4.14)
对区间 $I=[a,b]$，特征线 $x-ct=a$ 和 $x+ct=b$ 交于 $(t_*,x_*)$，
其中 $t_* = \frac{b-a}{2c}, \quad x_* = \frac{a+b}{2}$ (4.15)
围成三角形区域 $\triangle_I = \{(t,x) \mid 0 \leqslant t \leqslant t_*, a+ct \leqslant x \leqslant b-ct\}$ (4.16)
称为区间 $I$ 的**决定区域**。

任何形如 (4.5) 的函数 $u$ 满足函数方程 $u(t,x) + u(t+\xi+\eta, x+c\xi-c\eta) = u(t+\xi, x+c\xi) + u(t+\eta, x-c\eta)$ (4.17)
几何表述：对任何以四条特征线为边的平行四边形（特征平行四边形），
$u(A) + u(C) = u(B) + u(D)$ (4.18)
(4.18) 可用于求解初边值问题。

初边值问题：在带状区域
$\sqcup = \{(t,x) \mid t>0, 0<x<L\}$ (4.19) 内考虑方程 (4.1)，

初值条件
$t=0: \quad u = f(x), \quad u_t = g(x), \quad \forall x \in (0,L)$ (4.20)
边界条件
$u = h(t) \quad (t>0, x=0)$ (4.21)
$u = i(t) \quad (t>0, x=L)$ (4.22)
用过角点的特征线将带状区域分成小区域。

在区域 I 内由 D'Alembert 公式解出 $u$。区域 II 中任一点 $A$，作特征平行四边形 $ABCD$，由 (4.18) 得 $u(A) = u(B) + u(D) - u(C)$ (4.23)
其中 $u(B)$ 由边界条件给出，$u(C),u(D)$ 位于区域 I 可用 (4.13) 算出。

依次可得所有区域的值。若要求解 $u \in C^2$，在角点处需满足相容性条件
$\begin{cases} h(0) = f(0), & h'(0) = g(0), \quad h''(0) = c^2 f''(0), \\ i(0) = f(L), & i'(0) = g(L), \quad i''(0) = c^2 f''(L). \end{cases}$ (4.24)
若 $h(0) \neq f(0)$，则沿直线 $x=ct$ 解 $u$ 有跳跃。

分离变量法：设 $L=\pi, h(t)=i(t)\equiv 0$（齐次边界条件）。令
$u = \sum_{n=1}^\infty \alpha_n(t) \sin(nx)$ (4.26)
代入方程得
$\alpha_n'' + n^2 c^2 \alpha_n = 0$ (4.27)
解为
$\alpha_n = a_n \cos(nct) + b_n \sin(nct)$ (4.28)
由初值条件
$f(x) = \sum_{n=1}^\infty a_n \sin(nx), \quad g(x) = c\sum_{n=1}^\infty n b_n \sin(nx)$ (4.29)
得
$a_n = \frac{2}{\pi}\int_0^\pi f(x)\sin(nx)dx, \quad b_n = \frac{2}{cn\pi}\int_0^\pi g(x)\sin(nx)dx$ (4.30)

一维波动方程可化为一阶偏微分方程组。令
$u_1 = u, \quad u_2 = u_t, \quad u_3 = u_x$ (4.31)
得
$\begin{cases} \frac{\partial u_1}{\partial t} - u_2 = 0, \\ \frac{\partial u_2}{\partial t} - c^2 \frac{\partial u_3}{\partial x} = 0, \\ \frac{\partial u_3}{\partial t} - \frac{\partial u_2}{\partial x} = 0. \end{cases}$ (4.32)
