## 3 线性模型

### 3.1 基本形式
线性模型可解释性强（comprehensibility）。

### 3.2 线性回归

### 3.3 对数几率回归
对数几率函数（sigmoid）$y = \frac{1}{1+e^{-z}}$。
将线性回归 $z = w^T x + b$ 代入，得到$y = \frac{1}{1+\exp(-(w^T x + b))}$，
等价于 $\ln \frac{y}{1-y} = w^T x + b$。
对于二分类，有 $\ln \frac{p(y=1|x)}{p(y=0|x)} = w^T x + b$，可用极大似然估计求解。

### 3.4 线性判别分析 LDA
给定数据集 $D = \{(x_i, y_i)\}_{i=1}^m$，$y_i \in \{0,1\}$。
令 $\mu_0, \mu_1$ 分别为两类样本的均值向量，$\Sigma_0, \Sigma_1$ 为协方差矩阵。
LDA 目标最大化类间距离与类内距离之比：
$J = \frac{w^T (\mu_0 - \mu_1)(\mu_0 - \mu_1)^T w}{w^T (\Sigma_0 + \Sigma_1) w}$

类内散度矩阵 $S_w = \Sigma_0 + \Sigma_1$
类间散度矩阵 $S_b = (\mu_0 - \mu_1)(\mu_0 - \mu_1)^T$ $J = \frac{w^T S_b w}{w^T S_w w}$.
最优解 $w = S_w^{-1}(\mu_0 - \mu_1)$

实际计算时可对 $S_w$ 做奇异值分解 $S_w = U\Sigma V^T$，则 $S_w^{-1} = V \Sigma^{-1} U^T$。

推广至多分类
全局散度矩阵 $S_t = S_b + S_w = \sum_{i=1}^m (x_i - \mu)(x_i - \mu)^T$
类内散度 $S_w = \sum_{i=1}^N \sum_{x \in X_i} (x - \mu_i)(x - \mu_i)^T$
类间散度 $S_b = \sum_{i=1}^N m_i (\mu_i - \mu)(\mu_i - \mu)^T$
优化目标 $\max_{W} \frac{\operatorname{tr}(W^T S_b W)}{\operatorname{tr}(W^T S_w W)}$。

### 3.5 多分类学习
- OvO（一对一）：每两类训练一个分类器，投票。
- OvR（一对多）：每次将一个类作为正例，其余为反例。
- MvM（多对多）：使用纠错输出码（ECOC）。

### 3.6 类别不平衡问题
若正例数为 $m^+$，反例数为 $m^-$，则决策规则修正为：若 $\frac{y}{1-y} > \frac{m^+}{m^-}$ 则预测为正例，等价于再缩放 $\frac{y'}{1-y'} = \frac{y}{1-y} \times \frac{m^-}{m^+}$。

## 4 决策树

### 4.1 基本流程

### 4.2 划分选择
目标：使分支结点包含的样本尽可能属于同一类别，即纯度越来越高。
#### 4.2.1 信息增益
信息熵：$Ent(D) = -\sum_{k=1}^{|\mathcal{Y}|} p_k \log_2 p_k$，其中 $p_k$ 为第 $k$ 类样本比例
属性 $a$ 有 $V$ 个取值，用其划分 $D$ 得信息增益：
$Gain(D,a) = Ent(D) - \sum_{v=1}^V \frac{|D^v|}{|D|} Ent(D^v)$
选择 $a_* = \arg\max_{a} Gain(D,a)$

#### 4.2.2 增益率
信息增益偏向取值较多的属性，增益率定义为 $Gain\_ratio(D,a) = \frac{Gain(D,a)}{IV(a)}$
其中 $IV(a) = -\sum_{v=1}^V \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|}$（固有值）
通常先选出信息增益高于平均水平的属性，再从中选增益率最高的

#### 4.2.3 基尼指数
CART 决策树使用基尼指数
基尼值：$Gini(D) = \sum_{k=1}^{|\mathcal{Y}|} \sum_{k'\neq k} p_k p_{k'} = 1 - \sum_{k} p_k^2$
属性 $a$ 的基尼指数：$Gini\_index(D,a) = \sum_{v=1}^V \frac{|D^v|}{|D|} Gini(D^v)$
选择 $a_* = \arg\min_{a} Gini\_index(D,a)$。

### 4.3 剪枝处理（pruning）
防止过拟合
#### 4.3.1 预剪枝（prepruning）

在决策树生成过程中，对每个结点在划分前进行估计，若当前结点的划分不能带来泛化性能提升，则停止划分，将当前结点标记为叶结点，其类别标记为训练样例中最多的类别。

#### 4.3.2 后剪枝（postpruning）

先完整生成一棵决策树，然后自底向上地对非叶结点进行考察，若将该结点对应的子树替换为叶结点能提升泛化性能，则进行剪枝。

后剪枝通常比预剪枝保留了更多分支，欠拟合风险较小，泛化性能往往优于预剪枝，但训练时间开销更大。



### 4.4 连续与缺失值

#### 4.4.1 连续值处理

对于连续属性 $a$，在样本集 $D$ 上出现 $n$ 个不同取值，排序为 $a^1,a^2,\ldots,a^n$。取相邻两值的中点作为候选划分点，候选划分点集合为 $T_a = \{\frac{a^i + a^{i+1}}{2} \mid 1 \le i \le n-1\}$。

基于划分点 $t$ 可将 $D$ 分为 $D_t^-$（属性值 $\le t$）和 $D_t^+$（属性值 $>t$）。信息增益为 $\text{Gain}(D,a) = \max_{t \in T_a} \text{Gain}(D,a,t)$，其中 $\text{Gain}(D,a,t) = \text{Ent}(D) - \sum_{\lambda \in \{-,+\}} \frac{|D_t^\lambda|}{|D|} \text{Ent}(D_t^\lambda)$。

注：与离散属性不同，若当前结点划分属性为连续属性，该属性仍可作为其后代结点的划分属性。

#### 4.4.2 缺失值处理

给定训练集 $D$ 和属性 $a$，设 $\tilde{D}$ 表示 $D$ 中在属性 $a$ 上没有缺失值的样本子集。对于属性 $a$ 可取的值 $\{a^1,\ldots,a^V\}$，令 $\tilde{D}^v$ 表示 $\tilde{D}$ 中在属性 $a$ 上取值为 $a^v$ 的样本子集，$\tilde{D}_k$ 表示 $\tilde{D}$ 中属于第 $k$ 类的样本子集。若为每个样本 $x$ 赋予权重 $w_x$，定义 $\rho = \frac{\sum_{x \in \tilde{D}} w_x}{\sum_{x \in D} w_x}$， $\tilde{p}_k = \frac{\sum_{x \in \tilde{D}_k} w_x}{\sum_{x \in \tilde{D}} w_x}$， $\tilde{r}_v = \frac{\sum_{x \in \tilde{D}^v} w_x}{\sum_{x \in \tilde{D}} w_x}$。

则信息增益为 $\text{Gain}(D,a) = \rho \times \text{Gain}(\tilde{D},a)$，其中 $\text{Gain}(\tilde{D},a) = \text{Ent}(\tilde{D}) - \sum_{v=1}^V \tilde{r}_v \text{Ent}(\tilde{D}^v)$，且 $\text{Ent}(\tilde{D}) = -\sum_{k} \tilde{p}_k \log_2 \tilde{p}_k$。

在划分时，若样本在属性 $a$ 上缺失，则以概率 $\tilde{r}_v$ 将其划入第 $v$ 个子结点。



### 4.5 多变量决策树

多变量决策树（斜划分决策树）每个非叶结点不再仅对单个属性进行划分，而是对属性的线性组合进行测试，例如 $0.365 \times \text{密度} - 0.366 \times \text{含糖率} = -0.158$。这类决策树也称为“斜决策树”，能产生更复杂的决策边界。



## 第5章 神经网络

### 5.1 神经元模型

M-P神经元模型：神经元接收来自 $n$ 个其他神经元的输入信号 $x_i$，通过带权重 $w_i$ 的连接传递，总输入为 $\sum_{i=1}^n w_i x_i$，与阈值 $\theta$ 比较后经激活函数 $f$ 产生输出 $y = f(\sum_{i=1}^n w_i x_i - \theta)$。

常用激活函数：阶跃函数 $\text{sgn}(x) = \mathbf{1}\{x \ge 0\}$，以及 sigmoid 函数 $\text{sigmoid}(x) = \frac{1}{1+\exp(-x)}$。



### 5.2 感知机与多层网络

感知机由输入层和输出层组成，输出层为 M-P 神经元（阈值逻辑单元）。它能解决与、或、非等线性可分问题。学习规则：对训练样例 $(x,y)$，若当前输出为 $\hat{y}$，则权重更新为 $w_i \leftarrow w_i + \Delta w_i$， $\Delta w_i = \eta (y - \hat{y}) x_i$，其中 $\eta \in (0,1)$ 为学习率。若问题线性可分，感知机收敛；否则发生振荡。

非线性可分问题需使用多层网络，如多层前馈神经网络（无环路径）。常见结构有单隐层前馈网络和双隐层前馈网络。



### 5.3 误差逆传播算法（BP）

BP 算法基于梯度下降，以目标函数负梯度方向调整参数。设输入层 $d$ 个神经元，隐层 $q$ 个神经元，输出层 $l$ 个神经元。隐层第 $h$ 个神经元的输入为 $\alpha_h = \sum_{i=1}^d v_{ih} x_i$，输出为 $b_h = f(\alpha_h - \gamma_h)$（$\gamma_h$ 为隐层阈值）。输出层第 $j$ 个神经元的输入为 $\beta_j = \sum_{h=1}^q w_{hj} b_h$，输出为 $\hat{y}_j = f(\beta_j - \theta_j)$（$\theta_j$ 为输出层阈值）。

对训练样例 $(x_k, y_k)$，网络输出为 $\hat{y}_k = (\hat{y}_1^k,\ldots,\hat{y}_l^k)$，均方误差为 $E_k = \frac{1}{2}\sum_{j=1}^l (\hat{y}_j^k - y_j^k)^2$。

参数更新公式：
$\Delta w_{hj} = -\eta \frac{\partial E_k}{\partial w_{hj}} = \eta g_j b_h$， $\Delta \theta_j = -\eta g_j$，其中 $g_j = -\frac{\partial E_k}{\partial \hat{y}_j^k} \cdot \frac{\partial \hat{y}_j^k}{\partial \beta_j} = \hat{y}_j^k (1 - \hat{y}_j^k)(y_j^k - \hat{y}_j^k)$。

类似地， $\Delta v_{ih} = \eta e_h x_i$， $\Delta \gamma_h = -\eta e_h$，其中 $e_h = b_h(1-b_h) \sum_{j=1}^l w_{hj} g_j$。

标准 BP 每次更新针对单个样例，累积 BP 基于整个训练集上的累积误差。隐层神经元个数常通过试错法确定。

过拟合缓解策略：
1. **早停**：若训练误差降低但验证误差升高则停止。
2. **正则化**：在目标中加入网络复杂度项，如 $E = \lambda \frac{1}{m}\sum_{k=1}^m E_k + (1-\lambda)\sum_i w_i^2$。



### 5.4 全局最小与局部极小

参数优化可能陷入局部极小。常用策略：
1. 多组不同初始值训练，取误差最小的。
2. 模拟退火：以一定概率接受比当前更差的解。
3. 随机梯度下降（SGD）。
4. 遗传算法等启发式方法。



### 5.5 其他常见神经网络

#### 5.5.1 RBF 网络（径向基网络）

单隐层前馈网络，输出为 $\varphi(x) = \sum_{i=1}^q w_i \rho(x,c_i)$，其中 $q$ 为隐层神经元个数，$c_i$ 和 $w_i$ 分别为第 $i$ 个隐层神经元的中心和权重，$\rho(x,c_i)$ 为径向基函数（常用高斯形式 $\rho(x,c_i)=\exp(-\beta_i \|x-c_i\|^2)$）。训练步骤：1）确定中心（随机采样或聚类）；2）用 BP 确定 $w_i$ 和 $\beta_i$。

#### 5.5.2 ART 网络（自适应谐振理论）

竞争型学习，无监督学习策略（胜者通吃），能根据输入自动调整原型。

#### 5.5.3 SOM 网络（自组织映射）

无监督学习，将高维输入映射到低维网格，保持拓扑结构。

#### 5.5.4 级联相关网络

构造性网络，逐步加入隐层神经元并冻结已训练连接。

#### 5.5.5 Elman 网络

递归神经网络，隐层输出反馈回输入层，适于序列数据。

#### 5.5.6 Boltzmann 机

基于能量模型，能量函数为 $E(s) = -\sum_{i=1}^{n-1}\sum_{j=i+1}^n w_{ij} s_i s_j - \sum_{i=1}^n \theta_i s_i$，其中 $s \in \{0,1\}^n$，$w_{ij}$ 为连接权重，$\theta_i$ 为阈值。状态向量 $s$ 出现概率为 $P(s) = \frac{\exp(-E(s))}{\sum_t \exp(-E(t))}$。受限 Boltzmann 机（RBM）常用对比散度（CD）算法训练，更新规则为 $\Delta w = \eta (v h^\top - v' h'^\top)$，$v$ 和 $h$ 分别为显层和隐层状态向量。
